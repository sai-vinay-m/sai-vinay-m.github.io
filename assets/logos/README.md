# Logo assets

Add logo files to this folder, for example `company-logo.svg` or `technology-logo.png`.

Reference them from `index.html` with a relative path:

```html
<img src="assets/logos/company-logo.svg" alt="Company name">
```

Prefer SVG for scalable logos or transparent PNG for raster logos. Keep filenames lowercase and use hyphens. The existing résumé remains in the parent `assets/` folder.
