# Sai Vinay Mullapudi — Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. No build step or package installation is required.

## Included
- Responsive hero and navigation
- Seamless scrolling technology marquee (pauses on hover; reduced-motion support)
- Filterable project case studies
- Experience timeline, about section, education and certifications
- Dark/light theme toggle
- Email and LinkedIn contact links
- Resume download link placeholder
- SEO and social sharing metadata

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.



## Personalize before publishing
1. Confirm the displayed dates, role descriptions and certification names against your latest résumé.
2. Replace or remove any claim you cannot substantiate.
3. Check whether professional work details are safe to publish; the case studies are intentionally generalized.
4. Verify your contact information and LinkedIn URL.
5. Add a GitHub URL or project demos if you want them displayed.

## Free deployment
### GitHub Pages
1. Create a GitHub repository and upload the files in this folder.
2. In repository **Settings → Pages**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. Wait for the published URL shown in the Pages section.

### Vercel
1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Use the project root, with no build command and no output directory (static site).
4. Deploy. Review current provider terms and free-tier limits before launch.

## Important
The logo marquee uses styled text/monograms rather than externally loaded brand logo images, so it works without external icon services. It should be treated as a visual technology list, not proof of certification or endorsement.
